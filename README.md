# お礼LINEメーカー（長崎）

買取のお客様へ送るお礼LINE・返信LINEの文面を、ボタン選択と一言入力だけで作るツールです。
`index.html` 1枚で動作します（サーバー・インストール不要。Google Fonts のみ外部読み込み）。

## 元アプリとの関係

- 元アプリ：https://del-works.github.io/thanks-line/ （佐賀エリア版）
- 本アプリはそのコピーで、変更点は以下のみです。
  - タイトル・見出しを「お礼LINEメーカー（長崎）」に変更
  - 店舗一覧 `STORES` を長崎エリアの13店舗に差し替え
  - 店舗記憶用の localStorage キーを `thanks-line-nagasaki-store-today` に変更
    （同じ `del-works.github.io` ドメインで公開すると localStorage が共有されるため、佐賀版と記憶が混ざらないよう分離）
  - 署名の電話番号 `TEL` を長崎用の `0120-679-268` に変更
- 文面テンプレート・署名の店名「買取専門店 諭吉」・受付時間は元アプリと同じです。
  元アプリ側で文面を改修した場合、本アプリには自動反映されません（手動で取り込みが必要）。

## 改修ポイント

すべて `<script>` 冒頭の「テンプレート」ブロックにまとまっています。

| 変数 | 内容 |
|---|---|
| `SHOP` / `TEL` / `HOURS` | 署名の店名・電話番号・受付時間 |
| `STORES` | 店舗一覧（署名に入る表記そのまま）。1行追加で店舗が増えます |
| `OPENING` / `RESULT` / `CLOSING` | お礼文面（来店回数×結果で組み立て） |
| `REPLY` | 返信が来たときの文面 |
| `CHIPS_COMMON` / `CHIPS_BY_RESULT` / `seasonalChip()` | 「その方だけの一言」の候補 |

## フェイルセーフ（元アプリから継承）

- 店舗未選択のときは警告を表示し、コピーボタンを押してもコピーされない。
- 文面に「〇〇」が残っていると警告を表示。
- 店舗の選択はその日のうちだけ記憶し、日付が変わると未選択に戻る（前日の店舗のまま送る事故を防止）。
- クリップボードAPIが使えない環境では文面を全選択し、手動コピーを案内。

## 既知の制約

- localStorage が使えない環境（プライベートブラウズ等）では店舗の記憶が効かず、毎回選び直しになります（動作自体は可能）。
- `meta robots noindex` 指定のため検索結果には出ません。URLを共有して使います。
